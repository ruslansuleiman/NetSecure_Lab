# Техническое задание v0.1

## 1. Назначение

NetSecure Auditor анализирует текст конфигурации Cisco IOS, полученный командой `show running-config`, и обнаруживает опасные настройки, связанные с VLAN, trunk, ACL и базовой защитой управления.

## 2. Границы первой версии

В первой версии программа работает с одним текстовым файлом конфигурации и не подключается к устройствам по сети. Это осознанное ограничение: сначала проверяем корректность анализа, а автоматическое получение конфигураций добавим после освоения Packet Tracer.

## 3. Входные данные

Текстовый файл Cisco IOS running-config.

## 4. Выходные данные

Для каждого нарушения программа показывает:

- идентификатор правила;
- категорию;
- уровень серьёзности;
- краткое описание;
- найденную строку;
- рекомендацию по исправлению.

Также рассчитывается предварительный балл безопасности от 0 до 100.

## 5. Правила v0.1

| ID | Категория | Уровень | Проверка |
|---|---|---|---|
| ACL-001 | ACL | critical | найдено `permit ip any any` |
| ACL-002 | ACL | high | найдено `permit tcp any any` |
| VLAN-001 | VLAN | high | используется VLAN 1 как access VLAN |
| VLAN-002 | VLAN | high | native VLAN trunk равна VLAN 1 |
| VLAN-003 | VLAN | medium | trunk без `allowed vlan` |
| MGMT-001 | Management | high | включён Telnet (`transport input telnet`) |
| MGMT-002 | Management | medium | отсутствует SSH (`ip ssh version` или `transport input ssh`) |
| AUTH-001 | Authentication | high | есть `enable password`, но нет `enable secret` |
| PORT-001 | Switch port | medium | интерфейс неиспользуемого типа не выключен |

## 6. Критерий готовности

Аудитор должен обнаруживать все перечисленные нарушения в учебной уязвимой конфигурации и не падать при неполной конфигурации.
